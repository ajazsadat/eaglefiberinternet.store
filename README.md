# Eagle Fiber Internet

Next.js rebuild of [eaglefiberinternet.store](https://eaglefiberinternet.store/) — independent ISP comparison site for Eagle Fiber LLC.

## Stack

- Next.js 16 (App Router)
- Tailwind CSS 4
- React 19

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
